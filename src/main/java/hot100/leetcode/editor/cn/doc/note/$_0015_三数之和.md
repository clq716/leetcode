### 解题思路
- 去年看过灵神的解题视频，还记得大致的解题思路
- 排序 + 内层相向双指针 + 剪枝
- 剪枝遗漏了一个条件：`优化：如果当前元素与后面两个元素之和大于零，则结束循环`
```java
public List<List<Integer>> threeSum(int[] nums) {
        //......
	//如果当前元素大于0，则跳过循环
	if (nums[i] > 0) break;
	//应该修改为 如果当前元素与后面两个元素之和大于零，则结束循环
	if (nums[i] + nums[i + 1] + nums[i + 2] > 0) break;
	//......
}
```
- 内层循环的写法没有灵神的优雅，但思路是一样的
