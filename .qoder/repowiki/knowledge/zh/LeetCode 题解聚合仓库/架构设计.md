本仓库为 Maven 聚合工程（groupId=org.practise, artifactId=leetcode），通过顶层 pom.xml 统一声明 Java 25、Lombok、SLF4J-simple、Jackson XML 等依赖及 compiler/surefire 插件版本，供子模块 hot100 与 leetcode_solutions 共同继承；两个子模块均基于 LeetCode Editor 插件生成，按题目文件组织源码与 Markdown 笔记，彼此独立无运行时耦合，仅共享父 POM 的编译与测试配置。根目录还包含 export_leetcode.py 用于从本地题库导出已做题记录到 leetcode_solved.csv，以及 IntelliJ IDEA 工作区文件 leetcode.code-workspace 将两个子模块纳入同一 IDE 会话。
