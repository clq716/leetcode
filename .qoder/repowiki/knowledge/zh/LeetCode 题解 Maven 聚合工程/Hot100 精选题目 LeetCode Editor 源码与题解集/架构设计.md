本模块为纯源码/文档目录，按 LeetCode Editor 插件约定组织：
- `src/main/java/hot100/leetcode/editor/cn/` 下每个 `$_NNNN_中文标题.java` 对应一道题，类名即文件名，内部以 `class Solution` 包裹提交代码，并用 `//leetcode submit region begin/end` 注释标记不可修改区域；测试入口放在同文件的 `static void main()` 中，通过 `utils.Printer.print` 输出。
- `doc/content/` 存放由 labuladong 插件自动拉取的题目描述与多语言题解（含 HTML/CSS 标签）；`doc/note/` 用于手写笔记；`doc/solution/` 预留位置。
- 依赖方向单向：Java 源文件仅依赖外部 `utils.Printer`，不反向引用 doc 下的 Markdown。
