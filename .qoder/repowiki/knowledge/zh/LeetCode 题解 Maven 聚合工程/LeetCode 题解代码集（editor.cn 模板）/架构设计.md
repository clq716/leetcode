模块以 `leetcode.editor.cn` 为根包，每个 `.java` 文件对应一道 LeetCode 题目，采用 LeetCode Editor 插件的标准模板：外层类名即文件名，内部嵌套 `Solution` 类实现方法，并用 `//leetcode submit region begin/end` 注释包裹可提交区域；每个文件头部包含从编辑器导出的题目描述、示例、提示与 Related Topics 注释块。

目录分层清晰：
- `src/main/java/leetcode/editor/cn/*.java`：当前活跃的题解实现，按题目英文名或 `_NNNN_题号+英文` 命名。
- `src/main/java/leetcode/editor/cn/oldcode/`：历史/归档的旧实现，不再维护。
- `src/main/java/leetcode/editor/cn/test0327/`：临时测试入口。
- `src/main/java/leetcode/editor/cn/doc/{content,note,solution,submission}/`：与题目配套的 Markdown 题面/笔记、`.lcv` 视频解析片段以及提交记录文本，由编辑器同步生成。
- `src/main/java/leetcode/editor/common/`：共享工具类目录（当前为空，预留）。 
- `src/main/java/leetcode/labuladong/`：labuladong 插件数据缓存（`.lcpr_data`、`plugins.json`），与主代码无编译期依赖。
- `src/main/java/leetcode/lingshen/a_double_point_1/`：独立专题练习子包，使用自己的包名，不混入 editor.cn 模板。
- 顶层 `JacksonCheatParser.java`：独立的辅助脚本，不属于 editor 体系。

依赖方向单向：所有题解仅依赖 JDK 标准库，彼此之间通过各自 `main` 独立运行，不存在跨题解引用。
