该仓库是一个纯 Java LeetCode 题解练习项目，不包含任何前端代码。仓库结构为 Maven 多模块 Java 项目，主要包含：
- Java 算法题解代码（src/main/java/leetcode/editor/cn/）
- LeetCode Editor 插件生成的 Markdown 文档
- Maven 构建配置（pom.xml）
- Python 导出脚本（export_leetcode.py）

经搜索确认，仓库中不存在任何 CSS、SCSS、LESS、Tailwind 配置文件或前端框架相关文件，因此 frontend_style 类别不适用于此仓库。
